# Pinterest Pin Generator

Локальное веб-приложение: генерит картинки для Pinterest (формат 2:3, рынок США, рецепты),
льёт их на твой Cloudflare R2 и отдаёт готовый CSV для массовой загрузки.

Работает на твоём компьютере. Ключи хранятся локально в файле `.env` и в интерфейс не попадают.

---

## Что нужно один раз установить

1. **Python 3** (если ещё нет) — https://www.python.org/downloads/ (при установке на Windows поставь галочку «Add Python to PATH»).
2. Открой папку проекта в терминале и установи зависимости:
   ```
   pip install -r requirements.txt
   ```

## Настройка ключей (один раз)

1. В папке проекта скопируй файл `.env.example` и назови копию `.env`.
2. Открой `.env` в блокноте и впиши свои значения:

   **OpenRouter**
   - `OPENROUTER_API_KEY` — твой ключ OpenRouter (тот же, что у чат-агента).

   **Cloudflare R2** (панель Cloudflare → R2)
   - `R2_ACCOUNT_ID` — Account ID (виден в адресе S3-эндпоинта `https://<ЭТО>.r2.cloudflarestorage.com`).
   - `R2_ACCESS_KEY_ID` и `R2_SECRET_ACCESS_KEY` — создай в **R2 → Manage R2 API Tokens → Create API Token**, права **Object Read & Write**. Secret показывается один раз — сохрани сразу.
   - `R2_BUCKET` — имя твоего бакета.
   - `R2_PUBLIC_BASE` — публичный адрес бакета (r2.dev или твой домен), без слэша в конце. У тебя это `https://pub-cad6545ef3dd4639ba662249a6538de3.r2.dev`.

   > Картинки должны быть публично доступны для Pinterest, поэтому у бакета должен быть включён публичный доступ (R2 → Settings → Public access / r2.dev), как у твоего текущего.

### Про VPN и адрес 127.0.0.1
`127.0.0.1` (он же localhost) — это «сам твой компьютер». Он **не зависит** от VPN, интернета
или того, где ты находишься (дом, кафе). Приложение всегда открывается по этому адресу —
и с VPN, и без него. Запросы к OpenRouter и R2 идут напрямую (мимо системного прокси),
поэтому VPN на них больше не влияет.

Если при запуске увидишь **"Address already in use"** — значит приложение уже запущено
в другом окне терминала (или зависло). Закрой то окно или запусти на другом порту:
`PORT=5060 python3 app.py` и открой `http://127.0.0.1:5060`.

### Смена модели картинок
Прямо в приложении есть список **«Модель картинок»**:
- **Gemini Flash (Nano Banana)** — реалистично, хорошо с текстом и руками (~$39 / 1000).
- **Seedream 4.5** — фотореалистичная еда (~$30–50 / 1000).
- **GPT Image 2** — дёшево, но «ИИшно» (~$6 / 1000), для черновиков.

Базовый реалистичный стиль уже зашит в промпт — поле «Промпт» можно оставлять пустым.

## Как пользоваться

1. **Ключевые слова** — впиши до 10 (по одному в строке или через запятую). На их основе строятся промпты картинок, тайтлы и описания.
2. **Промпт / направление** — необязательно: общий стиль картинок (можно оставить пустым и добавить позже).
3. **Сколько картинок** — сколько сгенерировать за один заход.
4. **Качество** — Low (самое дешёвое, рекомендуется), Medium, High.
5. **Старт № файла** — с какого номера нумеровать файлы (по умолчанию 1). Удобно, если доливаешь в ту же папку.
6. **Папка на R2** — имя подпапки в бакете для этой пачки (например `1-pinterest-receipee-weeknight-dinners`).
7. **Ссылка на продукт** — пойдёт в колонку `Link`.
8. **Доски** — по одной в строке; если несколько, будут чередоваться по пинам.
9. Жми **Сгенерировать** — увидишь прогресс и превью. По окончании жми **Скачать CSV**.

Копия CSV также сохраняется в папку `out/`.

На каждой картинке модель рисует жирный заголовок-хук и CTA (призыв) — как у топовых recipe-пинов.

## Запуск в облаке 24/7 (Render) — чтобы ноут и интернет были не нужны

Генерация теперь идёт ФОНОВОЙ задачей на сервере: запустил из браузера → можешь закрыть
ноутбук/вкладку, задача продолжает крутиться на сервере. Зашёл позже на тот же адрес —
видишь прогресс и скачиваешь CSV. CSV ещё и автосохраняется на R2 после каждой пачки.

**Деплой на Render:**
1. Залей папку проекта в репозиторий GitHub (как делали с чат-агентом).
2. Render → New → Blueprint → выбери этот репозиторий (там есть `render.yaml`).
3. На шаге переменных заполни (sync:false) все значения из своего `.env`:
   `OPENROUTER_API_KEY`, `R2_ACCOUNT_ID`, `R2_ACCESS_KEY_ID`, `R2_SECRET_ACCESS_KEY`,
   `R2_BUCKET`, `R2_PUBLIC_BASE`, и **обязательно `ADMIN_PASSWORD`** (пароль на вход).
4. Plan: **Starter ($7/мес, всегда онлайн)** — на free-плане сервис засыпает и убьёт фоновую задачу.
5. Deploy. Получишь адрес вида `https://pin-generator-xxxx.onrender.com`.

**Как пользоваться (в облаке):**
- Открой адрес, введи пароль (`ADMIN_PASSWORD`).
- Заполни промпт/параметры, нажми «Запустить генерацию».
- Можешь закрыть ноутбук и уйти — сервер генерит сам.
- Вернулся, открыл адрес снова — страница переподключится к задаче и покажет прогресс.
- «Скачать CSV» берёт автосохранённый файл с R2 (`<папка>/_pins.csv`).

> Важно: `ADMIN_PASSWORD` обязателен в облаке — иначе любой с ссылкой сможет жечь твои кредиты.
> Если сервер перезапустится во время прогона (редкий деплой/сбой) — картинки и CSV на R2
> уже сохранены, просто запусти добор оставшихся с нужного «Старт № файла».

## Формат CSV (как в твоей таблице)

```
Title, Media URL, Pinterest board, Thumbnail, Description, Link, Publish date, Keywords, Status
```
- `Title` — уникальный, ≤ 100 символов
- `Media URL` — публичная ссылка на картинку в R2
- `Description` — уникальное, ≤ 400 символов
- `Keywords` — ключевые фразы
- `Link` — твоя ссылка на продукт
- `Thumbnail`, `Publish date`, `Status` — пустые

## Стоимость (ориентир)

GPT Image 2, формат 2:3: Low ≈ $0.006, Medium ≈ $0.05, High ≈ $0.19 за картинку.
Текст (тайтлы/описания на Haiku) — копейки. 100 картинок на Low ≈ $0.6 + мелочь за текст.
